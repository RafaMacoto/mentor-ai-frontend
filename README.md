# Mentor AI Career Path

Crie o frontend completo de um produto chamado Mentor AI, uma plataforma de requalificação e recolocação profissional com inteligência artificial.

O objetivo do MVP é ajudar pessoas que estão buscando voltar ao mercado de trabalho ou mudar de carreira a entender seu perfil profissional, definir um objetivo e receber um plano personalizado de desenvolvimento gerado por IA.

O frontend deve ter aparência de um SaaS moderno, profissional e confiável, com foco em tecnologia, carreira e inteligência artificial. Evite aparência genérica de dashboard administrativo.

16. Dados mockados

Como o backend ainda não precisa estar conectado, utilize dados mockados realistas.

Não crie apenas uma landing page.

O objetivo é construir uma aplicação SaaS navegável, simulando o fluxo completo:

Landing Page
→ Cadastro
→ Onboarding
→ Dashboard
→ Plano
→ Recomendação IA
→ Tarefas
→ Progresso
→ Perfil

Os dados devem ser estruturados de forma que posteriormente seja fácil substituir os mocks por chamadas à API REST do backend Spring Boot.

17. Integração futura com backend

Prepare o frontend pensando que o backend será uma API REST desenvolvida em:

Java 21
Spring Boot 3
Spring Security
Spring Data JPA
Oracle Database

A IA do backend utiliza:

Spring AI
Groq API
Llama 3.1 8B

Não é necessário implementar a integração real agora, mas organize o frontend de maneira que seja simples conectar endpoints posteriormente.
